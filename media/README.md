# 启动视频

Windows Release 安装包包含 `startup.mp4`，规格为 2560×1600、30 帧/秒、32 秒。当前仓库源码包不包含这份约 73 MB 的预渲染视频。

构建完整安装包时，从本项目 Windows Release ZIP 取出该文件并放到本目录。`build.ps1` 构建播放器与安装器，不渲染动画。

动画自有部分、AI 人物和第三方品牌标识的授权范围见根目录的 NOTICE.md 与 CREDITS.md。

视频中的验证、成功提示和欢迎语是非官方预制演出，不是真实认证或官方表态。当前成片保持原样；其中第三方标识的再分发许可尚未完成核验。完整范围见 [NOTICE.md](../NOTICE.md)，权利反馈见 [RIGHTS.md](../RIGHTS.md)。
